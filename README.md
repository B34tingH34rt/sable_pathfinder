
# Sable: Pathfinder

Sable: Pathfinder is a Minecraft 1.21.1 NeoForge mod by B34tingH34rt.

It improves mob pathfinding across Sable sub-levels.

## Development

Run the client from your IDE's generated Gradle run configurations, or use:

```sh
./gradlew runClient
```
